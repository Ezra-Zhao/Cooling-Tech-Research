# Cooling-Tech-Research

冷凝（冷却）技术研究专栏。每周一篇，用大白话把散热讲透。

Data center cooling and condensation technology, one study note a week, explained in plain language.

## 每篇怎么写（固定五段）

1. **研究的问题** — 这次要弄明白哪一件事（结露、换热、PUE、液冷……）
2. **原理翻成人话** — 热怎么走、水怎么走、冷怎么来
3. **关键参数和数字** — 温差、流量、能效、成本，写清条件
4. **数据中心里怎么用** — 适用场景、坑和限制
5. **结论** — 值得上吗、谁适合上
